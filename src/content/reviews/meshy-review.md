## Key Features & Production Pipeline

### 1. High-Fidelity Text-to-3D & Image-to-3D
Meshy's dual generation modes allow creators to kickstart 3D workflows at any stage:
* **Text-to-3D:** Enter a prompt like *"a futuristic cyberpunk katana with glowing neon runes, low-poly game asset"* and Meshy generates a 3D preview in 20 seconds, followed by a high-resolution mesh refinement pass.
* **Image-to-3D:** Upload a single PNG or JPEG concept art file. Meshy infers the hidden 3D volume, back-face geometry, and spatial depth, turning 2D illustrations into 3D meshes with faithful proportions.

### 2. Physically Based Rendering (PBR) Texturing
Generative 3D tools often fail because they bake flat, pre-lit colors directly onto vertex maps. Meshy avoids this by generating true **PBR Material Sets**:
* **Albedo (Base Color):** Clean diffuse color maps without baked lighting artifacts.
* **Normal Maps:** High-frequency surface detail that simulates depth without inflating polygon counts.
* **Roughness & Metallic Maps:** Precise surface reflection maps for realistic metallic and non-metallic material interactions in realtime renderers.

### 3. Polygon Density & Polycount Control
For real-time game engines (Unreal Engine 5, Unity, Godot) or mobile AR experiences, polygon budgets are critical. Meshy allows creators to define target polygon limits before export—ranging from mobile-friendly **low-poly models (<5,000 tris)** up to detailed **high-poly assets (>50,000 tris)**.

### 4. Seamless Blender, Unity, and Unreal Integration
Meshy supports a dedicated Blender Plugin and native file exports (`.FBX`, `.GLB`, `.OBJ`, `.USDZ`), allowing artists to drag generated assets directly into existing 3D software pipelines without manual file conversion.
